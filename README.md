# Translation Lab（翻訳選択実験）

作品「それ、本当にあなたが訳したんですか？」的体验网站。

- **体验页面**：`index.html`（单一文件），通过 GitHub Pages 公开，任何拿到链接的人都能体验。
- **后台**：Google 表格上的 Apps Script（`apps-script/Code.gs`），负责两件事：
  - AI 生成（訳A・B、评语和訳C）
  - 写入体验记录：**只记录在开头选择「同意して進む」的来场者**；选「同意せずに体験する」的来场者什么都不会发送
- **API 密钥**：只保存在 Apps Script 的「脚本属性」里，不会出现在网页或这个仓库中。

---

## 设置步骤

### 1. 在 Google 表格中加入 Apps Script

1. 打开用来统计的表格，点菜单「扩展程序 → Apps 脚本」。
2. 删除编辑器里原有的代码，把 `apps-script/Code.gs` 的全部内容粘贴进去，然后保存（Ctrl＋S）。
3. 在函数下拉菜单中选 `setup`，点「运行」。
   - 第一次运行会请求授权，选择你的 Google 账号并允许。
   - 如果出现「Google 尚未验证此应用」，点「高级」→「转至……（不安全）」继续。这是你自己写的脚本，所以会出现这个提示。
   - 运行完成后，表格里会出现「記録」和「集計」两张工作表。

### 2. 填入 API 密钥

1. 在 Apps Script 编辑器左侧点齿轮图标「项目设置」。
2. 在页面最下方的「脚本属性」中点「添加脚本属性」：
   - 属性：`ANTHROPIC_API_KEY`
   - 值：你的 Anthropic API 密钥
3. 保存。

可选的属性：

| 属性 | 默认值 | 说明 |
|---|---|---|
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | 想更便宜、更快就填 `claude-haiku-5-5` |
| `RATE_LIMIT_PER_10MIN` | `120` | 每 10 分钟最多接受多少次 AI 生成（全体合计） |

### 3. 部署为网页应用

1. 点右上角「部署 → 新建部署」。
2. 点「选择类型」旁的齿轮，选「Web 应用」。
3. 设置：
   - 执行身份：**我**
   - 谁可以访问：**任何人**
4. 点「部署」，复制显示的「Web 应用」网址（以 `/exec` 结尾）。
5. 把这个网址交给 Claude，或者自己填进 `index.html` 开头 `CONFIG` 里的 `backend.url`。

> 以后修改了 Code.gs，需要在「部署 → 管理部署」里编辑现有部署，把版本改为「新版本」后再部署，网址不会变。

### 4. 开启 GitHub Pages

1. 打开本仓库的 Settings → Pages。
2. 「Build and deployment」的 Source 选 **Deploy from a branch**，分支选 **main**、文件夹选 **/(root)**，保存。
3. 一两分钟后，网站会发布在 `https://marybaaai.github.io/translation-lab/`。

> 免费账号只能对**公开（Public）仓库**使用 GitHub Pages。仓库里没有 API 密钥，公开也没问题。

### 5. 确认

- 打开网站，右上角显示「AI接続：あり」就表示 AI 连接成功。
- 按 Ctrl＋Alt＋S 打开工作人员设置，可以看到与表格的「接続」状态和未发送记录的件数。
- 选「同意して進む」体验一次，确认「記録」表多了一行，「集計」表的人数也随之增加。

---

## 记录的内容

「記録」表一位来场者一行：体验ID（随机生成，不含个人信息）、时间、翻译方向、难度、原文、看 AI 译文之前的理解度、最初选择的方法、第一次提交的译文、看评语后是否修改、最终译文、自我评价、一致率、参考值、訳A・B・C 和评语等。

- 来场者从报告返回、重新做自我评价时，会覆盖同一行，不会重复记录。
- 断网或连接失败时，记录会暂存在该设备的浏览器中，连接恢复后自动补发。
- 「集計」表用公式自动统计人数、各项比例和平均值，新记录进来后会自动更新。

## 修改内容

- 原文、文字、判定标准：`index.html` 开头的 `CONFIG`
- 给 AI 的指示：`index.html` 中的 `TLAB_PROMPTS`，以及 `Code.gs` 末尾的同一段（两处保持一致）
- 会场设置：在页面上按 **Ctrl＋Alt＋S**
